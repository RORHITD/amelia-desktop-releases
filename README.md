# Amelia's Agent — Desktop downloads

The Mac and Windows app for [ameliasagent.com](https://ameliasagent.com/desktop).
Your computer becomes the machine: free forever on your own hardware, your code
never leaves it, and the six-digit pairing links it to your phone.

**[Download the latest release →](https://github.com/RORHITD/amelia-desktop-releases/releases/latest)**
